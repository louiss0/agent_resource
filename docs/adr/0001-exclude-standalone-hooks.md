# Exclude standalone hooks as a resource category

Although Claude Code, Codex CLI, and Antigravity all support declarative lifecycle hooks (`PreToolUse`, `PostToolUse`, `Stop`, and related events) in `settings.json`, `hooks.json`, or `config.toml`, Agent Resource excludes standalone hooks from its managed Resource taxonomy and keeps `hooks` strictly as a subordinate native field on Agent and Skill definitions where applicable. Unlike Skills, Prompts, Agent definitions, MCP server registrations, and Context templates, native hook entries are anonymous nested array items without a primary name or identifier key, split a single logical capability between a shared configuration entry and an external executable script, and couple matchers and stdio payloads to harness-specific tool names and schemas—making standalone lifecycle management and cross-harness conversion high-complexity with low portability value.
